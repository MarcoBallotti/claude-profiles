# Product

Claude Profiles is a local desktop utility for people who use their own personal, work and client Claude accounts on one computer. Their primary task is choosing the right account and opening its existing Claude Desktop or Claude Code installation without repeated logout/login cycles.

The product preserves the standard personal setup, separates new profile directories, and offers intentional import and selective preference copying. It never creates or sells accounts, reads credential stores, rotates quotas or synchronizes private conversations. It is not affiliated with Anthropic.

The scope is macOS, Windows and Linux desktop users with keyboard and mouse. Existing native macOS profile paths are preserved during migration. The app uses native file dialogs and system terminals, with an English UI and Italian getting-started guide. Desktop authentication compatibility remains experimental and is described honestly.

The incumbent warm sidebar/detail design is preserved. This is a platform migration, not a new brand exercise.
